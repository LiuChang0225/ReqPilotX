# Runner parity

Codex Desktop Reference and Codex App Server Product are adapters for the same
Portable Agent Kit. They may differ in transport, thread identifiers, timing,
token accounting, cancellation, resume, sandbox, and deployment metadata.

They may not differ in policy, ontology, Skills, references, pinned scripts,
declared tools, model, reasoning effort, proposal schemas, validators, or stage
completion semantics. Compare page and record coverage, boundary merge/split
errors, semantic disposition, assertion/facet fidelity, unresolved disclosure,
and cross-stage lineage. Do not require byte-identical generative JSON or use a
single count as parity.

Rich Desktop discovery is useful for finding missing capabilities, but it is
not a gate. A discovery result becomes a product capability only after the
needed context/tool/rule is externalized into the Kit and reproduced by both a
hermetic Desktop cold run and the App Server runner.
