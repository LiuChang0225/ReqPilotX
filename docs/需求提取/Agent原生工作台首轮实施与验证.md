# Agent 原生工作台首轮实施与验证

2026-09-10。用户在[整体评估与方案](Agent原生工作台整体评估与方案.md)后明确“很好，继续”。本轮完成文档台账、同源条目表格、常驻任务区与阶段主区的首个应用增量；既有客户原件、账本、模型任务和人工决定未被重新处理。

## 已实施

- **文档台账**：项目选择收进可搜索入口；客户文档与内部知识分开。逐文档读取实际工作版与任务状态，四并发限制；已有成果/任务分列，支持搜索、需处理/处理中/可审阅筛选和原件预览。上传成功后沿用同一来源列表刷新。打开已有工作版直接去清单，阶段草稿去结构，不默认进入技术诊断。未载入时不显示假零值。
- **同源条目表格**：普通工作台默认表格审阅，沿用既有有序ledger和筛选、选择、原文详情；可切回结构/PDF。表格显示稳定编号、分类、响应及其来源；工程师当前意见优先，派生单元不冒充父项整体结论；原表/图片继续在完整内容和来源核对。支持上下方向键与Home/End，定位当前与树表切换共用选择。
- **常驻协作区**：`DocumentWorkSurface`持有当前文档任务，宽屏停靠，窄屏切换成果/协作；不覆盖原文。结构、清单、分析和导出共用任务区。文件名、工作版、已选SRC/REQ在输入旁可见；视图卸载清理选中条目与刷新回调，防止导出页误沿用上一条目范围。
- **新文档任务简报**：原件保存后显示目标和预期成果、原件预览、内部依据策略及结构确认偏好，用户明确开始才提交任务。新文档页面不再同时出现旧推断式驾驶舱和另一套开始按钮。
- **阶段主区**：已有MAP/ITEMS直接在主区核对内容与PDF；ITEMS保留需求编号、判断与类别。确认卡绑定确切来源/Map，过期版本不能当有效确认；新阶段到达保留正在核对的版本，提供显式切换。只有成果查询已确定没有工作版后，才自动打开初始阶段，避免异步竞争错误落到旧Map。
- **进度与历史**：公共目标和job更新时间经原有GET返回；公开commentary随事件更新。终态读取顺字节cursor补齐，长历史分批继续；当前任务公开动作和旧成果生成记录分别保留在协作区，移除普通页面独立“运行轨迹”入口。没有模拟百分比或将页面选择当作Agent真实工作。
- **重试与导出**：未决请求保留command_id，网络结果未知时同内容重试复用；原工作草稿导出增加用途与未决响应摘要，并响应任务保存后的刷新。既有来源hash、人工意见和程序导出合同沿用。
