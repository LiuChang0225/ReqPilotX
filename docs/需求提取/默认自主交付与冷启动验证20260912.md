## 运行后已修复的两个具体断点

**首次交付收尾。** 原`review-close`需要revision-receipt/candidate，且只接受review内的delivery；workspace导出却落在task/outputs。Sol公开轨迹实际编制了一份业务文件完全相同的candidate来尝试结束，不应全部归因模型能力。现在`workspace run deliver`对当前review的COMMITTED导出自动验证并登记，接着`review-verify`即可；已有导出可用`review-attach-delivery`登记。真正修订仍走原review-close。

登记重核当前完整snapshot、来源/Map/baseline/所有overlay和Excel，保持旧head CAS与幂等；必要时将完整delivery复制到review自有内容地址目录，不改原导出、不制造业务版本或人工接受。ATTACH_FAILED保留原COMMITTED导出并说明实际原因。此自动适配在portable workspace wrapper，未声称native direct-deliver也已改为相同入口。

在独立Sol副本上17项检查全部通过：原模型171个文件前后摘要一致；副本10个业务文件、Map/baseline/原件/Excel/snapshot不变；无新candidate，业务目录仍versions/initial，只有交付登记元数据head；verify通过并可幂等重试。证据明确标为PROGRAM_REPAIR_ON_COPY_NOT_MODEL_SUCCESS。冻结构建包再次执行副本review-verify通过，原模型仍未close。

**辅助图零范围诊断。** 新image-packet仅在真实同源capture证明图像只有回源引用或被明确排除、没有可用所属图像时提供非阻断image_binding_note，给原页、ref及正确绑定入口。不会凭reason文字猜业务、不自动建SRC；无图、缺证据、异源或无关scope保持合法空结果。短例明确辅助图可经content/numbered_body.continuations归入条款，evidence_refs不是可释读/导出的图像归属。18项新旧图像/Map相关检查通过。

两修复整合后103项plugin回归通过，当时安装`0.3.0+codex.20260912092411`，154有效文件构建/personal/cache一致，doctor READY。原8336运行包保持冻结。**该修复时点尚未运行92411冷启动；随后复测已另立记录，不改写前述8336超时成绩。**
