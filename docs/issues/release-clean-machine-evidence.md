# 目标部署环境仍需独立发布验收

## 当前状态

该事项未排期。当前开发以目标态验证为先，不能把历史桌面包、Windows 或云部署检查
提前变成阶段一的开工门禁。

## 触发条件

用户明确要求阶段三的实际交付环境或正式发布。
届时按所选形态验证安装/启动、Agent 登录与依赖、权限、任务恢复、数据备份、
卸载/回滚和客户数据边界。若选择桌面包再验签名与目标系统，不默认新增桌面产品要求。

## 保留能力

本地运行、安全与发布预检、备份/迁移及打包脚本保留。
当前 PostgreSQL/对象存储是既有应用真相，不用旧 SQLite 回滚新数据。

源码测试和一台开发机的结果不等于干净机器、客户环境或生产 SLA。
顺序见[开发计划](../需求提取/开发计划.md)。
