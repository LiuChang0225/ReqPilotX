决策日期：2026-08-24；公开摘要整理：2026-09-20。原稿混有真实案例统计、私有证据和旧安装状态，保留于私有工作区。现行对象以[模型 V1](文档结构与原文条目模型V1.md)为准。

默认工作形成来源忠实基线：文档组织、原文条目、需求/非需求判定、分类、角色、定位与解释都可核对。原文不能被规范化改写或派生文本代替。

需求拆分在明确授权的原文范围执行。请求绑定来源、基线版本与父项；派生项保存直接依据、共享条件、双向追溯和变换类型。无新增义务、完整保留条件/单位/例外、共同覆盖父意图是检查重点。父项保留且不与子项重复计数。

程序负责验证来源身份、顺序、覆盖、版本与持久化；Agent 根据完整上下文作语义判断。Parser 与表格算法提供材料化能力和候选边界，不成为业务权威。表格物理行数不等于需求数量。

工作台和 Excel 使用同一有序账本。真实 1:1 的结构/条目共用显示行，1:N 才展开。原文、图片释读、Agent 建议和人工决定分别标明。人工反馈可选介入；当前默认自主草稿策略覆盖早期“逐条确认”叙述，明确要求的确认仍绑定真实版本执行。
