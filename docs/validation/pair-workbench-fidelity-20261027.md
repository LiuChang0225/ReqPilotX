# PAIR 完整工作台复用与验收

日期：2026-10-27。范围：R08 的原设计保真修复。服务接入、界面与交互、真实业务结果、安装分发分别验收。

## 源码与构建

用户选定较新的 `pr10-employee-trial` 工作区作为 UI 依据；本分支保留其新版首页、导航、文档起始页和共享工作台，再加入宿主适配。独立发布工作树与原工作区分别保存，原工作区的 Python 业务改动未复制。独立本机模型配置编辑器及其后台 WIP 也未纳入；PAIR 中的模型、认证和执行继续由宿主拥有。

UI 与适配代码从同一分支构建。服务使用已提交业务引擎和服务的非 editable 安装，独立 PostgreSQL、对象目录及 fixture home。具体源码、文件哈希、构建回执和本机路径保存在私有 `publication-inputs.json`、构建日志及运行回执中。PAIR 依赖已与 G0 的 `sessionController.selectSessionModel` 核对；本轮不修改 PAIR Desktop、共享 Provider 或根依赖。

全部资料为程序生成的合成阀模块 PDF，未使用客户原件。MAP、ITEMS 初始成果由已有编译器及测试决策生成，属于 UI fixture，不是 AI 提取或来源语义成绩。

- 在真实 PAIR Web 中创建项目、上传 PDF，核对保存后的文档台账；原版 Web 与 PAIR 使用同一业务服务和数据。
- 打开包含 8 条原文、7 条需求、1 条保留内容的工作，选择 REQ-0004，核对全文、原编号、类别及 PDF 的精确来源框。
- 输入未发送意见并刷新，重新进入后仍保留选中条目、核对版本和意见草稿；保存意见后显示“待外部任务取回”，不启动模型。
- 保存“待内部证据”的工程师意见，生成成果 v3；回看 v2 时人工意见仍为 0，并保持历史版只读及最新成果提示。
- 保存 DRAFT 交付 v1，实际从浏览器下载 Excel。文件哈希与服务端保存的导出哈希一致，工作簿包含 `ComplianceMatrix`、技术测试表、图文依据及元数据，工程师理由保留。正式版因响应未齐而禁用，没有把草稿升格为正式接受。
- 在真实 macOS Electron 中打开同一首页、文档、程序读取和 v3 成果工作台。程序读取报告 1 页、1 表、3 图、22 个候选，并明确尚未形成正式 SRC 或分类。
- 真实 DSH profile 的脚本供应商探针验证任务绑定、MCP `task_open`、持久请求和重试去重，远端模型调用为 0。

独立工作树执行 `npm run typecheck`、共享 UI/适配构建、前端回归、CSS 投影测试及适配器聚焦回归。精确命令、计数和运行环境保存在同轮私有日志及 PR Evidence 中。依赖额外故障环境的重连矩阵未因这些检查而自动视为通过。

## 证据与边界

原版和 PAIR Web 的对照使用相同窗口尺寸与同一合成项目/文档/成果。操作 GIF 来自实际浏览器动作和返回状态；浏览器控制没有连续视频接口时使用同一运行的截图序列，说明每帧停留时长，不将其解释为实时响应耗时。源截图、GIF、QA 帧、下载核验和构建回执仅在忽略的 `.playwright-mcp/` 或私有运行目录保存；发布的审查媒体单独存放。

| 验收层 | 本轮结论 | 尚未成立的结论 |
|---|---|---|
| 服务接入 | 独立安装、自管 API/PostgreSQL、共享业务读写和真实 MCP 绑定已验证 | 不代替 UI 或业务质量 |
| 视觉与交互 | 完整共享工作台已在 Web/Electron 实际打开并操作；空态、文档、成果、历史版、意见、导出分别核对 | 待产品审阅与更多屏幕/资料类型验证 |
| 真实业务结果 | 本轮没有真实模型任务或客户需求验收 | R09 登录、选定实际文档、结果质量及工程师接受仍待完成 |
| 安装与分发 | 本机开发态 Electron 已验证 | Mac 安装包、Windows x64 构建/安装及公司网络验收未执行 |

来源移除和知识导入等宿主未提供的动作保持不可用；AI 阅读等额外服务能力不由挂载 UI 自动取得。程序读取只有在匹配服务并显式声明 `workbenchCapture` 后启用。原作者、适配贡献者、维护者及默认推荐仍按 PAIR 管理分发规则单独核实。

已保存业务成果由服务持久化；Agent 任务可按项目、文档、来源哈希和工作引用恢复，避免跨端口缓存丢失后盲建新任务。视图偏好和未发送草稿目前仍依赖浏览器 origin 存储：同源刷新恢复已验证，动态端口 Desktop 的完整偏好/草稿迁移属于底座稳定 origin/存储整合前提，不在本轮假定成立。

## CI 复核

远端首轮后台检查暴露六项失败，其中两项旧前端导航断言仍要求“需求提取”。断言已同步为当前“AI 辅助阅读／需求整理”，两个原有测试文件共六项用例通过，来源与评审不变量继续保留。其余失败对应未修改的资源计数及测试隔离文件；在选定原始基线中已复现技能计数 37／36 和 `test_private_web_trial.py` 隔离缺失。两项冻结 bundle 检查的本机基线复现因磁盘不足未完成，不能据此宣称它们通过。完整远端检查仍须处理这些失败，本 PR 保持草稿，不作合并就绪声明。
