# 目标部署环境仍需独立发布验收

## 当前状态

用户于 2026-10-01 要求约七天内交付 Windows 11 单机版，并分别接入 Azure OpenAI
与阿里云百炼。当前源码基线 `a7d9d29` 的桌面自检只覆盖 test/SQLite、无模型、无
durable worker，不能作为员工全链验收。原工作区有大量未提交改动，应先对账并保全。

本轮独立候选在 Mac 上把原文 Agent 主链的文件锁改用现有 Windows/POSIX 共用租约，
并取消“存在百炼 key 即强制启用 Qdrant”的启动行为。聚焦测试与编译结果见本轮交接；
这些结果未覆盖 Windows 包运行、PostgreSQL/worker 生命周期或模型调用。
冻结桌面包另有 `sys.executable` 原本会重启桌面 EXE 的阻塞；本轮候选已加入
受限插件脚本和来源捕获模块分派。仍须以同一个 Windows 发行包实测实际工具调用、
依赖收集和进程退出；源码 Python 测试不能替代。开发源码构建能力包不作为冻结
包的使用路径，应使用已注册的发行能力包。

混合正文＋表格的核心来源合同、插件输入与Excel已在独立候选上通过合成回归。
独立应用的窗口任务新增单表节点成对执行：表格候选声明精确正文跨度，正文候选确认
同一表格记录键和跨度，两者一起校验后只发布一版基线；合成 worker 任务在正文执行中断时
未发布半条记录，重试后发布 1 条混合 SRC/REQ。多表节点仍拒绝此局部路径，需联合计划。
真实模型草稿、UI/Excel 端到端及员工安装链仍需逐项验收；合成通过不计作自主链通过。

## 触发条件

交付候选应在干净 Windows 11 上逐家验证：安装与首次配置、受控 PostgreSQL/API/
worker 生命周期、真实部署的模型工具调用、授权 PDF 的完整来源草稿、人工反馈与
同版 Excel、取消/断网/重启恢复、备份与升级保留。记录候选版本、系统、非秘密
配置、失败与未运行项；Mac 测试和远端 CI 均不能替代此证据。

## 保留能力

本地运行、安全与发布预检、备份/迁移及打包脚本保留。
当前 PostgreSQL/对象存储是既有应用真相，不用旧 SQLite 回滚新数据。

源码测试和一台开发机的结果不等于干净机器、客户环境或生产 SLA。
顺序见[开发计划](../需求提取/开发计划.md)。
