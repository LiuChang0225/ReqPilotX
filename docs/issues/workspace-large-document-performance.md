# 大文档核对与运行性能证据

## 当前事实

工作台已有窗口化树/Matrix、单项 Inspector、表格与 PDF 工作面，
同树显示完整有效业务层级，不是只显示 REQUIREMENT/HYBRID。
历史 DOM 数字、旧 adapter RSS、旧单次模型耗时不代表当前版本整体性能。

## 触发与范围

第一阶段：如果用户核对受到明显等待、卡顿或状态丢失影响，就对当前案例做聚焦测量和改进。
阶段二/三：在确定宿主和部署环境后记录首个可检查结果、全文完成、反馈修订、恢复、
工具/模型耗时及 PDF/表格内存与 payload。

不为性能删掉必要上下文、视觉读取或来源校验；不假设增加并发必然加快。
局部边界判断、模型/工具往返、材料化、传输和浏览器渲染应分开测量。

## 当前未排期事项

目标 Windows/云环境容量和长时运行只在明确选择交付形态后验收。
构建大小与第三方测试警告记录在基线记录，不为清理工作引入无关架构重写。
