# Normal route and case index

Read this once for a new document. Start with the ordinary route; consult a special case only when its evidence is present. Read [the shared contract](business-contract.md) for identity and authority. Never preload every reference or the full API manual.

## Ordinary route

1. Use the already supplied project, source role, version, output location and internal-evidence choice. Resolve genuinely missing inputs; do not ask again for established facts. Open/guide the existing workbench when available.
2. Capture the original when matching-source evidence is not already available. For readable native PDFs, use positioned text and native tables, checking representative pages and every suspected gap. An orderly document does not need blanket OCR. Survey the whole document for units, headings, tables, figures and missing attachments.
3. Form the actual document tree: source order, direct body, nested clauses, logical tables and real attachment ownership. Show the structure before the ledger; honor a requested confirmation point.
4. Form complete source items, then judge requirementness/class/role from their governing context. Preserve related images and shared conditions. Program checks validate exact source coverage and identities.
5. Make authorized decomposition decisions, perform evidence-based analysis only where applicable, and publish the same-version Matrix/Excel. Keep unresolved ranges and actual stage results available for revision.

## Bounded reading and repair

After PDF capture use the [reading workspace](tools-capture.md) when offered: establish an overview, read complete page Markdown/table context in semantic scopes, inspect original pixels, then revise the hypothesis if evidence disagrees. Reuse matching-source views. Contact sheets are navigation only; 2x pages may still require focused crops for formulas or nested small tables. `reading-packet` is optional data inspection, not the default whole-document reading method.

For declared reference-parity runs, inspect every page in the declared scope at readable resolution and record actual checks. Selected method experiments and adaptive product reading have different scopes; never claim full-document visual coverage from representative pages. Parser candidates and risk flags cannot restrict access to other authorized evidence. Do not preload later-stage manuals.

Use existing task state and receipts for source/version, artifact paths and completed operations; do not maintain a duplicate hand-written version/path ledger. Record actual reading/visual findings and unresolved ranges that are not captured by those receipts. In a host without structured progress, a concise private note can retain the resume context. Returned image bytes or program inventory counts do not establish Agent understanding or source coverage. On resume, reuse matching-source state and recheck changed or disputed ranges plus governing context.

Ask what evidence the next call will resolve. For an ordinary numbered clause, its full text and governing heading may suffice. For a numbered BOM, check the table header, merged cells and notes against T02 before deciding a group; for a page-sized table containing several headings, check the original page before assigning owners. Do not conclude that every numbered row is a requirement or that every parser table is one business table.

Compile a coherent candidate, then repair the named failure locally. Read the relevant input contract once. Preserve the intended source semantics: never delete a cover role or merge unrelated sections merely to make validation pass. If the same failure recurs without new evidence, inspect a minimal diagnostic and record the affected capability gap; do not restart the entire document. Publish available stage results with remaining ranges visible. Passing coverage checks does not establish a correct hierarchy.

## Normal cases and the evidence that changes them

The snippets below are synthetic. They describe target semantics, not a claim that every parser can express every boundary.

| Case | Ordinary handling | When handling changes |
|---|---|---|
| N01 Readable single-column specification | Use native text/geometry; verify heading/body order and source coverage | Missing/garbled visible text, scans or wrong column order → [R03–R05](source-reading.md#reading-evidence) |
| N02 `4.2 Communication` followed by one complete requirement | One visible clause/item, retain heading and body | Pure heading with several numbered children → preserve structure plus leaf items; parent body remains its own content |
| N03 `4.2.1` and `4.2.2` independently state obligations | Two original items under 4.2, with governing context | BOM part numbers or steps jointly defining one test → [T02–T03](tables-and-relations.md#choose-the-business-unit) |
| N04 One unnumbered statement spans two paragraphs | Keep its complete meaning; use PARAGRAPH for ordinary prose | Independent obligations may need separate source ranges or authorized Snn; punctuation alone is insufficient → [J07](judgment-cases.md#decomposition-and-response) |
| N05 Two independent parameter rows under a governing requirement | One complete parameter/condition/value/unit record per property | Rows collectively define one packet, composition or method → [T01–T04](tables-and-relations.md#choose-the-business-unit) |
| N06 Cover and contents precede the body | Whole readable structural blocks; no per-field/entry SRC | Independent front-page obligation, or mixed navigation/body range → [R01](source-reading.md#role-and-structure) |
| N07 Figure illustrates a nearby clause with an explicit reference | Keep it with that clause; original and Agent reading stay separate | Independent normative drawing or uncertain ownership → [R08](source-reading.md#reading-evidence) |
| N08 Stable reviewed baseline receives local feedback | Revise the affected source/relationships, preserve unaffected IDs and valid opinions | Changed source or governing context requires dependent re-review; do not renumber to conceal changes |

## Select a guide by the uncertainty

| Question you actually need to resolve | Read |
|---|---|
| Wrong role, heading/continuation, scan, watermark, bilingual text, attachment, figure | [Source reading: R01–R09](source-reading.md) |
