# 工作台全流程 UI 排查与修复

更新：2026-09-12。依据用户“继续探索发现并优化当前 UI，全流程，全操作，全入口排查问题”的授权，接续统一工作台首个切片。此次覆盖现有项目、文档、阅读、提取、分析、协作、交付、知识库和设置入口，直接修复可证实的交互问题；没有改造业务算法、运行新模型或全面替换历史 Set/candidate 流程。

## 结果

主要问题集中在入口恢复、异步状态真实性和窄窗可用性。已修复首次无项目的创建死路、失效链接误开其他来源、跨任务丢失清单位置、旧插件记忆覆盖显式原生选择、交付历史跨来源残留等问题。表格中的完整父条款、独立派生行、来源编号和当前查看版本继续保留。

前端主回归 **274 项／28 文件通过**，补充运行与上传边界检查 **18 项／3 文件通过**（部分重复覆盖，不相加），TypeScript 与生产构建通过；对主任务增量的独立代码复查未发现严重回归。补充暂停检查确认只发送当前任务暂停命令，不提交或清空未发文字。测试覆盖多入口与异步失败，不等于所有后台执行器或模型质量均已实测。
