# ReqPilotX 当前接续

更新：2026-09-20。本文只记录同步源码基线的状态。产品能力见[项目状态](项目.md)，实施顺序见[开发计划](需求提取/开发计划.md)。

## 当前基线

源码、测试、配置模板和共享业务合同进入版本控制。客户原文、逐字案例、页图、真实答案、运行数据库、模型轨迹、凭据及本机安装回执保留在私有工作区，不随源码分发。取用规则见[源码与私有资料边界](源码与私有资料边界.md)。

版本以所检出提交、`plugins/reqpilot/.codex-plugin/plugin.json`、能力包清单及运行时实际返回的身份为准。旧开发报告里的安装时间、版本号、PID和端口不证明当前安装或服务在线；新任务应重新执行对应 doctor/readiness 检查。

本次同步验收区分程序回归、合成闭环、授权真实文档局部验证和完整产品验收。同步范围的最终执行证据随本次交付提供；未执行项不得沿用历史成绩。源码基线可复现不代表所有产品功能或所有文档类型均已验收。

## 已有能力

- 共同业务核心支持来源读取、Document Map、SourceItem、分类、显式派生、反馈、版本与程序 Excel 导出。
- 原生应用、便携插件和 Pair 适配共享业务核心，宿主协议和生命周期分别适配。
- 工作台保留来源、版本、原序、原表/原图、人工意见和多工作选择；程序检查与人工接受分别记录。
- 无内部依据时跳过自动符合性分析，继续来源整理、缺项说明及人工响应。

## 产品后续范围

完整 Pair Agent 发起/自动绑定/进度/交付、响应与人工依据完整传输、旧入口整理、复杂 PDF 的独立语义复现及 Office 全链继续按开发计划推进。历史阶段成功与未通过记录不自动改变上述边界。

大型模块拆分和构建体积优化作为后续工程任务，按实际影响单独验证，不借同步过程批量改写业务。
