## 1. 四种证据分开记录

| 证据 | 证明什么 | 不证明什么 |
|---|---|---|
| 自动测试与静态检查 | 代码合同、边界、状态和已知反例 | 新文档语义全部正确 |
| 产品负责人案例验收 | 真实案例结果与核对体验符合目标 | 任意文档/宿主都能复现 |
| 独立复现与泛化 | 新会话、新文档、指定宿主下的重复能力 | 未测试宿主、无限文档或生产 SLA |
| 发布验收 | 指定环境的部署、权限、恢复、容量与交付 | 被跳过或未授权运行的外部能力 |

SourceIR COMPLETE/PARTIAL 是捕获状态；断言 PASS/FAIL/GAP/BLOCKED_INPUT 是评测状态；
案例聚合和用户接受又是另一层。不要把数量一致、无异常或返回 JSON 当作语义 Gold。
