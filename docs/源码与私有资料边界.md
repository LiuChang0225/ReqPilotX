# 源码与私有资料边界

更新：2026-09-20。此源码基线用于复现 ReqPilotX 的实现和程序合同，不分发客户资料或本机运行状态。

## 随源码提供

业务实现、测试代码、明确人工创作的合成输入、配置模板、业务定义、接口与部署说明。合成例必须独立创作并标明性质；更换客户名、文件名或数字不把真实衍生资料变成合成数据。

内置知识图谱为两组隔离的小型合成演示，用于核对导航、检索和图谱交互，不提供客户技术参数或产品符合性答案。通用解析器的水印处理按版面特征工作，不携带特定客户水印名录。

## 在私有环境保存

客户原件、OCR/转写、页图、源条目与派生答案、真实知识库与 Wiki、模型轨迹/评分、数据库、对象存储、服务回执和凭据。历史原稿仍在原工作区及其备份中；本候选的正文撤出不删除原资料，也不改写旧客户结果。

需要这些资料时，由资料所有者明确提供授权输入路径与验证范围；使用对应工具支持的显式输入参数。缺少资料时报告 `PENDING_INPUT` 或明确跳过，不读取其他项目、猜测开发机路径、下载来源不明的替代品，或以空文件伪装验证通过。

测试运行使用隔离目录和合成来源；真实验证的输出仍放私有目录。源码只记录范围、方法、结果与未完成项，避免复制客户正文或私有答案。

## 版本与验收

记录源码提交、能力包身份、输入哈希、环境和实际命令的结果；安装、程序检查、合成闭环、真实局部语义和完整产品验收分别说明。历史数量不是新版本的通过证据，当前未完成的产品范围见[项目状态](项目.md)。

仓库被忽略的文件不会由 Git 备份；运行数据需单独按[部署说明](deployment/local-native-postgresql.md)执行备份与恢复验证。Git 历史中若已有私有内容，删除当前文件不会清理历史；发布分支应单独审核其可达历史和将推送的对象。
