# ReqPilotX 项目状态

更新：2026-09-20。ReqPilotX 是汽车 SOR 需求工程工作台，连接来源理解、原文条目与分类、显式派生、内部证据、工程师响应及同版本 Matrix/Excel。

本文描述产品实现边界，具体提交的验证结果以该次执行证据为准。完整产品尚未全部验收；同步基线的可复现程序检查不能替代语义质量、完整宿主流程或工程师接受。

| 领域 | 已有实现 | 验收边界 |
|---|---|---|
| 提取与插件 | 来源、Map/Items、分类、派生、反馈、稳定版本及 Excel；提供 CLI/MCP | 混合 PDF、跨页完整单元和上下文需要独立语义复核；安装成功不证明提取正确 |
| 原生应用 | App Server 任务、动态工具、事件、恢复和成果保存 | 已有实际保存证据；仍须按具体任务验证来源、完整性和交付 |
| Pair 适配 | 托管服务、项目/PDF 入口、共享 UI 和只读成果面板 | 完整 Agent 发起、自动工作绑定、真实进度和完整交付尚未整体验收 |
| 工作台与导出 | 原文树、源定位、原表/图、工作/版本选择、反馈和同版程序导出 | 旧入口整理及完整响应/人工依据传输仍有后续工作 |
| 工程师意见 | 独立保存、人工优先、撤销、版本失效和导出合同 | 合成意见不代表客户正式响应；不得替历史客户数据补造意见 |
| 来源捕获 | 文字、表格、图像、定位、续表和共享上下文候选 | OCR/算法提供证据，不自动决定语义边界 |
| Office | 原生定位与部分程序链路 | PDF 优先；完整 Office 产品流程尚未整体验收 |
| 运行存储 | PostgreSQL、LocalObjectStore、durable jobs、稳定来源和版本 | 私有数据独立备份；新机器按部署说明准备，不依赖旧 PID 或本机绝对路径 |
| 互操作 | Matrix 与 Excel | ReqIF writer 尚未交付 |

当前开发顺序见[开发计划](需求提取/开发计划.md)，产品定义见[PRODUCT](../PRODUCT.md)，版本和交付入口见[当前接续](active-context.md)。
