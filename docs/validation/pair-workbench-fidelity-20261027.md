# PAIR 完整工作台复用与验收

日期：2026-10-27。范围：R08 的原设计保真修复。服务接入、界面与交互、真实业务结果、安装分发分别验收。

## 源码与构建

用户选定较新的 `pr10-employee-trial` 工作区作为 UI 依据；本分支保留其新版首页、导航、文档起始页和共享工作台，再加入宿主适配。独立发布工作树与原工作区分别保存，原工作区的 Python 业务改动未复制。独立本机模型配置编辑器及其后台 WIP 也未纳入；PAIR 中的模型、认证和执行继续由宿主拥有。

UI 与适配代码从同一分支构建。服务使用已提交业务引擎和服务的非 editable 安装，独立 PostgreSQL、对象目录及 fixture home。具体源码、文件哈希、构建回执和本机路径保存在私有 `publication-inputs.json`、构建日志及运行回执中。PAIR 依赖已与 G0 的 `sessionController.selectSessionModel` 核对；本轮不修改 PAIR Desktop、共享 Provider 或根依赖。

## CI 复核

四项失败已在本机复现。额外文件为 `reqpilot/references/source-unit-methods.md`，来自用户选定基线中已提交的方法示范（`068c4d7f`）；该提交同步更新 canonical source、插件投影及目录树身份，源码和投影字节一致。原测试仍固定为 36 项当前技能／42 项发行资产，未包含这一已登记成员。

测试改为核对该已审定提交的完整成员路径、SHA-256 和长度快照，共 37 项当前技能与 6 项 PDF 能力；兼容 Agent Kit 的版本和身份保持原有检查。冻结 bundle 正常安装及两个消费者对额外技能／PDF 文件、篡改、重复、缺失和链接的拒绝检查继续保留。运行时资源目录、目录哈希和发行校验器未改变，不以当前输出自动批准新资产。

`test_private_web_trial.py` 在导入试用脚本前实际调用现有隔离助手，支持 package 和原始 discovery 两种入口。新增子进程检查以临时继承目录作为对照，验证导入后存储位置、测试模式、对象目录和 Agent 后端已隔离，继承目录的配置字节不变。所用目录都是新建合成环境，不接触原业务环境。

受影响的资产、发行拒绝、路径隔离、试用脚本和运行设置五个测试模块共 34 项通过。负向对照确认：数量不变但资产哈希被改时失败；移除实际隔离调用时原始 discovery 入口失败，package 入口仍由包初始化器保护；恢复后两项聚焦检查通过。后续 CI 以本 PR 当前 head 的真实结果为准。隔离插件／真实 MCP stdio 套件另通过 302 项。前端 CI 随后暴露导出测试以账本响应用于交付预览／历史接口，异步子组件读取错误数据后可能卸载刚出现的标题；补上子组件完成断言后已稳定复现原失败。测试现按路径提供三类实际响应并等待交付历史就绪，三个相关文件 27 项及完整前端 96 个文件、1,148 项通过，类型检查通过。

UI 及生产运行源码未变，沿用此前演示提交的真实 Web／Electron 证据并在 PR 保留绑定，不把本次测试修复描述为新的模型或业务验收。

## 冷启动与异步选择隔离

独立审查后的生命周期修复覆盖两条合并条件：同一挂载内从业务 READY／任务未就绪变为任务可用，以及切换工作／核对版时的乱序观察和控制回执。之前的界面录像仍只证明其绑定提交的工作台保真，不代替本节新增行为验证。

实际 Client 组成的 React 测试先复现配置刷新后任务按钮仍禁用，修复后验证启动能力、撤销能力、模型、程序读取和任务查找配置更新；同一应用／端点的业务传输和工作台保持挂载，真实嵌入组件的业务阅读上下文也在任务配置变化时保持引用稳定。共享宿主回归先复现八条选择污染路径，修复后覆盖晚到的成功／失败、A→B→A、尚未加载的新核对版与最新版本、两个并行控制、旧观察落后于控制回执，以及新任务确认后用户已选其他工作。旧请求不会改变当前选择、清除新版本、释放另一个控制的忙碌状态或生成旧轮询。

观察取消还通过真实任务控制器验证：被取消请求即使收到响应，也不覆盖新意图、不读取旧 Session；已取消观察不发起请求。取消只影响观察，任务／控制请求的持久确认不回滚。现有宿主和工作台相关七个文件共 46 项、完整前端 98 个文件 1,161 项及类型检查通过；重新构建共享面板与适配器后，适配器检查 60 项通过、31 项额外故障环境用例跳过。CI 另暴露的证据登记单测已改为等待对应状态刷新请求后再检查次数，不以成功提示代替 effect 完成；知识业务源码未变。完整 CI 继续以审查 PR 的当前 head 为准。
