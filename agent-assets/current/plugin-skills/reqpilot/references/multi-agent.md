# Delegation and independent checking

Delegate only when the user or applicable workspace instructions authorize it. Roles are bounded responsibilities, not separate databases or mandatory model sessions.

| Role | Inputs | Concrete output |
|---|---|---|
| Orchestrator | request, source identity, bundle contract | run scope, assigned units, integrated current artifacts, exceptions |
| Source mapper | raw source, capture, source-map skill | source-bound ownership/heading/table decisions and unresolved capture spans |
| Source-item curator | exact Document Map, original source and scope | explicit text/table boundaries and classifications with source references |
| Technical reviewer | baseline, authorized parent IDs, original context, supplied internal evidence | explicit children, evidence-linked analysis and missing-input questions |
| Cold verifier | raw source, fixed candidate, business contract and declared scope | independent findings with severity, exact locator, observed mismatch and affected IDs |

The source mapper finishes ownership before curators process sibling scopes. The orchestrator allocates source/requirement IDs through the shared compiler after integration, rather than letting workers issue competing counters. A verifier does not silently replace a proposal; the producer or orchestrator repairs supported findings and the verifier checks the revision.

Cold verification excludes producer reasoning, answer counts, expected categories, private prior feedback and historical candidate paths. Give a realistic request, the skill, the original and the exact candidate needed for checking. Run outputs in a new private directory. The verifier can report source gaps and cannot grant formal customer approval.

Store a coordination receipt containing role, actual agent or session ID when available, input/source/bundle hashes, scope, output paths, start/end status and public findings. No dummy IDs and no invented work trace. If no independent Agent ran, set `independent_agent_verification` to `NOT_RUN`; deterministic validation remains a separate receipt.

A whole cold-session test begins in an empty workspace containing only the installed plugin, project AGENTS, raw inputs and a minimal request. It must regenerate source capture, Map, SourceItems, authorized children, analysis and Excel. Reopening a historical completed result is continuation, not a cold test. Record execution commands and errors, inspect real output, and distinguish a partial usable draft from full-source completion.
