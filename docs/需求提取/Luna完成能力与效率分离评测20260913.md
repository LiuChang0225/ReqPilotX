# Luna 完成能力与效率分离评测

更新：2026-09-13，按用户本轮纠正执行。

## 原判断的问题

20分钟是主Agent为评测脚本设置的默认运行预算，不是用户给出的硬要求，也没有用实际完成耗时分布校准。它可以用于观察阶段进度，但连续在20分钟杀进程后，只能确认“截至该时点未完成”，不能据此判断模型最终无法完成或最终交付质量必然不合格。

此前“未达标/不能稳定交付”的表述须限定为这些时间盒内的观察，不能解释为能力上限已经测出。20分钟时仍存在的BOM分组等具体错误有事实依据，但也不能假定模型获得更多时间后不会自查修复。质量要求保持不变；需要调整的是观测和终止方式。
