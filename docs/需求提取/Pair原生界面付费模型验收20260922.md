## 实跑发现

**原生应用启动路径漏接了既有 MCP。** 评测入口 `evals/agent_evals/hosts.py` 会挂载 ReqPilot MCP；原生 `TaskLauncher` 目前只准备冻结 CLI 与任务简报，再创建 standard Session，没有相同的 MCP 配置。因此本轮模型多次使用 shell 写入参数 JSON、另读结果、另取图片路径再调用图片工具。模型确实持续调用工具，但机械调用负担不能直接解释为模型能力不足。

下一项应补任务范围的 MCP 挂载：沿用相同冻结包与工作目录，每个任务隔离工具状态；不把一个任务的 MCP 挂在全局后让所有会话共享，也不在 Pair 重写业务工具。DSH preset 是按 preset 的 standing scope 共享，不可把任务相关绝对路径写入所有会话共用的 standard preset。接入完成后需验证工具发现、双任务隔离、关闭回收，再做独立付费实跑；本轮 CLI 结果不得改称 MCP 结果。

界面还显示 UUID 工作区名与泛化 request.md 会话名，用户辨识性不足；后续以原文件名/委托命名，底层稳定 ID 保留。
