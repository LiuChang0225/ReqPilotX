# 逻辑表显示名与来源标识

2026-09-08：逻辑表可以使用 Agent 明确给出的短显示名，原 Map 标签、客户标题证据、章节关系和原表内容保持独立。该合同补足错误表名的修订入口；不会替生产 Agent 给具体表命名。

## 数据与修订

`DocumentMapLogicalTableV1` 新增可选 `agent_display_label`。缺省为 None，并在 typed/native Map 序列化中完全省略；所有旧 Map 哈希、旧 scope request 和无新标签的 snapshot 字段和值保持原样。非空显示名必须是明确的字符串决策，空白或错误类型拒绝。原 `title` 保留为**原 Map 标签**，不能据此新增客户原文权威；真实源标题、表头、标题节点、cell、fragment、anchor 与 source handle 不改变。

在现有 `compile-map` 的 `logical_tables` 决策中提供 `agent_display_label`，随后通过现有 `review-revise` 的 Map 候选操作编译、导出及验证。无需新工具，也不允许通过创建虚构章节或改写源标题实现表格导航名。已有 `table_changes` 回执记录前后字段差异；所有来源守恒检查继续执行，修改真实 `title` 仍受原有来源证据约束。

共享 `document_map_table_presentation(table)`：

- 无显式标签：返回空 presentation，使用原有 `title`，不注入新元数据。
- 有显式标签：返回 `{display_title, authority: AGENT_DISPLAY_LABEL, map_title}`。`map_title` 仅是原 Map 标签，不称作客户原标题。

Map 本身绑定 source SHA、scope 和完整表格事实；scope request 另绑定当前 Map SHA。新 scope request 的可见 `logical_table_title` 使用显示名，同时在可选 `logical_table_presentation` 中明确来源。它不是可引用为客户逐字证据的字段。

## 同一展示链

- native 原表读面保留 raw `title`，仅在 `presentation` 返回上述投影，原始 reference 保持精确可重编译。
- review packet 返回该表的 `table_presentations`；scope 模板使用同一投影。旧无标签 packet 不增加此字段。
- snapshot 的逻辑表 `title` 与 `projection.title` 使用纯显示名，来源元数据仅在 `projection.title_presentation` 中出现。
- 原文工作台、条目原表视图及 Matrix 完整原表视图优先显示新名字，并显示简短“显示名（AI）”；不会把它改成原文条目正文或新章节。
- Excel sheet 名、原表 A2 标题与主表链接使用同一名字；原表 A3 标明“显示名（AI）”。无标签时所有原有文字不变。

显示名不参与原文事实或语义归属判断。合成全链中，7 个分析单元的 `units` 输入逐字段完全相同；全部判断正常继承，失效数为0。SourceItem 原文、SRC/REQ、分类、祖先关系、原表单元格和图像绑定保持不变。
