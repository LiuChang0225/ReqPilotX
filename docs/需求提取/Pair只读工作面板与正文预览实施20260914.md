# Pair 只读工作面板与正文预览：共享前端首增量

日期：2026-09-14。用户授权按共源计划实施，本UI任务负责宿主无关业务面板，整体插件任务负责DSH注册与Host包装。没有新起提取模型、替换评测案例或修改客户成果／eval／skills；没有重载18080、PG或worker。

## 实际变化

| 范围 | 已实现行为 |
|---|---|
| 单一业务UI | `PluginWorkbench`拆为原外壳适配与`PluginWorkbenchContent`，Standalone与宿主面板共享业务工作面及`usePluginWorkbench`；未复制分类、反馈或版本逻辑 |
| 挂载入口 | `src/host/index.ts`导出`ReqPilotXReadonlyPanel`，不createRoot、不接管宿主history／html主题、不要求旧Agent配置；首切片读取已有`plugin-*`工作 |
| 读取与文件 | 实例级readClient、resource／PDF URL注入，共同request解析保持。图片、知识原件和导出采用宿主地址；PDF跨origin支持准确parentOrigin，并继续检查实际父窗口 |
| 会话绑定 | host／workspace／session与project／document／source／work匹配才可打开。用户点击时传当前revision、node、SourceItem和Snn；不自动prompt，选中上下文未就绪时拒绝扩大为整文 |
| 真实进度 | 宿主运行观察与业务成果分别显示；未知即未报告、断连即断连，SUCCEEDED只表示会话本轮结束。逐token状态不重读整份成果，目录已有工件不算本轮Agent完成提取 |
| 历史版本 | 保存事件按来源／work过滤；新head只提示，不替换当前核对版。Map-only版本显示结构，选中状态回调交宿主保存 |
| 只读保护 | provider与HTTP client阻止写入；编辑／确认入口禁用或移出。旧结构proposal、继续及范围运行也有动作层保护，避免sourceReader误走原生写接口 |
| 正文预览 | 纯编号label等于已登记原编号时，对可见行读取既有text_bindings；校验source／baseline／Map和条目身份，略过独立编号，显示正文段并标“原文摘录”。不写回label、编号或上下文 |
| 样式与根说明 | 共同CSS构建为面板作用域，主题／动画名局部化，使用容器宽高；根节点兜底改为中性“独立文档单元” |

## 产物与对接

准确接口见[Host接入说明](../../prototype/frontend/src/host/README.md)及`prototype/frontend/src/host/readonlyHost.ts`。

`npm run build:panel`生成：

- `prototype/frontend/dist-panel/reqpilotx-readonly.js`：ESM，约380kB。
- `prototype/frontend/dist-panel/reqpilotx-readonly.cjs`：CommonJS，约295kB，供DSH包装lazy-CJS工厂。
- `prototype/frontend/dist-panel/reqpilotx-readonly.css`：共同index／workbench源生成的作用域样式，约469kB。

当前实际externals为`react`、`react/jsx-runtime`、`react-dom`；构建也显式排除`react/jsx-dev-runtime`和`react-dom/client`。宿主注入同一React／DOM实例；主Web应用的React19依赖保持。构建目录已忽略提交，不作为第二份可编辑业务源。

DSH仍需提供实际注册、文件通道、持久work↔Session绑定、面板恢复及真实事件来源。`openSession`只打开会话并准备上下文，不自动发送；取消、恢复、正式响应和业务写入不属于此只读入口。

## 边界

实际Pair sidebar/main注册、lazy-CJS包装安装、Session持久绑定与真实Pair事件由整体插件任务接入。共享库与相同React版本可用，不等于已经完成Pair内完整应用验收。

首轮覆盖便携工作和PDF只读成果；原生work、项目创建／上传、阅读问答、写反馈／正式响应／锁定尚未全部迁移。预览不能解决错误条件关联，程序预置阶段工件不等于本轮Agent新增成果。真实benchmark继续使用既定案例及全文件范围。
