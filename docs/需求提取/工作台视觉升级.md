# 工作台视觉升级

2026-09-10。用户明确要求参考 [Beautiful UI](https://www.beautifului.dev/) 升级现有工作台，使其更适合 Agent 协作。本轮聚焦前端呈现与可达性；现有来源、语义判断、人工意见及版本合同沿用。

## 已完成

- 新增独立 `prototype/frontend/src/styles/workbench.css` 工作台样式层：中性侧栏、白色阅读面、绿色主动作与选择、轻量工具栏和树行，以及对应深色主题；保留系统字体和现有栏宽控制。
- Agent 协作使用非模态 body portal，显示真实状态、阶段成果、公开处理动作与本轮结果。阶段成果位于长结果说明之前，有阶段成果时默认折叠长结果；反馈区包含当前来源/工作版/条目范围与草稿建议。
- 建议按钮只填写草稿。主动打开时聚焦输入，阶段自动出现不抢焦点；关闭按钮和 Escape 返回入口。继续、暂停、补充意见与原有接口/授权合同不变。
- 修复协作浮层受容器裁切或低窗口影响的问题；修复窄屏侧栏展开时主工作区误入 72px 网格列、导航主副文字混行的问题。

## 实际验证

- React 相关回归：7 文件、217 项通过，涵盖工作台导航、协作任务、阶段成果、来源动作、阶段导航和真实主核对组件。最终焦点修订后补充验证：2 文件、12 项通过，包含自动阶段显示不抢焦点、portal 脱离裁切祖先、Escape 恢复焦点及建议不自动提交。
- `npm run build` 通过（含 TypeScript）。构建仍提示既有主 bundle 超过 500 kB；本轮未处理模块拆包。
- 测试命令使用 `NODE_OPTIONS=--no-experimental-webstorage`，避免当前 Node 自带 localStorage 与 jsdom 冲突。首次未加此参数时出现 `localStorage.clear is not a function`，不计为通过。
- 已在本机正式 `http://127.0.0.1:8000` 检查最终构建；没有重启 API 或 worker。
- 实际 DOM 视口：1920×1080、1440×900、1023×675 和 1025×675。页面没有水平溢出；窄屏自动收为 72px 侧栏，协作面板位于 y=12–523，输入/关闭/继续按钮可达。修复后展开侧栏时主工作区仍为 x=72、宽953（1025视口），主副导航文字恢复 grid 分行。
- E01 原文清单的编号搜索、选中条目、PDF 原文位置及协作面板已实查。Oil Pump r17 的既有 42 项结构草稿可通过阶段成果打开；没有执行结构确认或启动新的模型任务。
- 明暗主题均通过实际截图检查，独立 finish reviewer 的焦点和侧栏问题已修正。开发热更新过程中曾出现已有运行信息列表的重复 React key 提示（`1:general` 等）；该列表不属于本轮改动，没有据此声称全站控制台无警告。

截图、构建/测试日志与改前局部文件保存在忽略目录 `prototype/runtime-data/ui-upgrade-20260910/`。`workbench-final.png` 为最终浅色工作台，`dark-compact.png` 为深色窄屏，`light-stages.png` 为既有阶段成果；它们是 UI 检查证据，不代表原文语义已经通过人工验收。
