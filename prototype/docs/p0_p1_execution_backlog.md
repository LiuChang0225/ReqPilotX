## 1. 实施原则
- 先准确率，后效率：P0 全部闭环后再推进 P1。
- 每个任务必须有可验证验收标准。

## 2. P0（必须先完成）

### P0-01 章节完整提取模式
- 模块：`app/services/extractor.py`
- 目标：默认按章节/子章节输出完整需求块，不按句子打散。
- 验收：抽查 3 份核心 PDF，章节内容完整率 >= 95%。

### P0-02 章节树一致性校验器
- 模块：`scripts/` + `app/services/extraction_preview.py`
- 目标：自动检测缺号、跳号、重复号、异常层级。
- 验收：能自动捕获 `5.3.9.3 -> 6` 这类异常并输出报告。

### P0-03 表格安全解析
- 模块：`app/services/extractor.py`
- 目标：表格数值不再被误识别为章节（如 `12.5mm`, `6.3mm`）。
- 验收：指定回归样本中该类误识别为 0。

### P0-04 跨页标题合并
- 模块：`app/services/parser.py`, `app/services/extractor.py`
- 目标：页尾章节号 + 下页标题自动合并。
- 验收：跨页标题样本识别成功率 >= 90%。

### P0-05 去噪强化 2.0
- 模块：`app/services/parser.py`
- 目标：基于位置+频次+碎片特征联合去水印/页眉页脚。
- 验收：审阅台残留噪声可见率显著下降，并输出残留统计字段。

## 3. P1（P0 完成后推进）

### P1-01 迭代差异审阅
- 模块：`app/static/extraction-review.*` + 对比 API
- 目标：支持 `rN vs rN+1` 按文档/章节/条目差异查看。
- 验收：可视化展示新增/丢失/变化条目。

### P1-02 错误闭环面板
- 模块：`phase0` 数据聚合 + 看板
- 目标：把错误标签自动聚合成可执行修复任务。
- 验收：可按错误类型输出 Top 问题与建议动作。

### P1-03 高风险样本队列
- 模块：`scripts/phase0_*` + `phase0-review`
- 目标：自动给出最可能误拆页，优先人工复核。
- 验收：队列命中率高于当前随机抽样。

### P1-04 需求判定模板化
- 模块：`app/static/app.js`, `app/main.py`
- 目标：支持批量判定模板（结论+原因模板）。
- 验收：批量操作可在主控台完成并落库。

### P1-05 证据可追溯展示
- 模块：`app/services/rag.py`, `app/static/app.js`
- 目标：每条判定展示证据来源与定位。
- 验收：导出与界面均可追溯“需求->证据->结论”。

### P1-06 版本化导出
- 模块：`app/services/exporter.py`, `app/db.py`
- 目标：支持当前版与对比版 Compliance Matrix 导出。
- 验收：同一项目可导出多版本并带版本标识。
