# ReqPilotX 问题记录

此目录保存值得跨会话保留的技术或产品问题。它是可选知识库，不是开工流程，也不约束开发顺序。

## 什么时候记录

- 当前任务无法安全解决，但问题会影响后续决策；
- 需要真实样本、外部环境或用户选择才能继续；
- 问题横跨多个模块，值得留下复现证据和验收条件。

能在当前任务中直接修复的问题可以直接修复，无需先建记录。

## 建议内容

每个问题一个 Markdown 文件，名称使用稳定的英文短语。正文尽量包含：

- 当前影响和用户可见结果；
- 可复现证据或相关代码位置；
- 已知边界与不应做的假设；
- 可验证的完成条件；
- 当前状态：`open`、`in_progress` 或 `resolved`。

历史字段（如 capability、work_package、track）可保留作审计，但不需要继续填写，也不引用进度注册表作为权威来源。
