# Map the original

本阶段输入是客户原件、任务范围和已有来源材料；产物是**按原件真实阅读顺序、可回查原页的结构树**。保留完整正文、真实祖先与编号边界，恢复表格/图片归属和跨页关系，同时说清已处理范围与疑点。及时保存并在已接入的工作台展示，自查发现的问题由你回源修正；具体入口与接入范围见[工作台说明](../reqpilot/references/tools-host.md#workbench-entry-and-current-limits)。仅有Map文件不代表前端已显示。完整整理任务默认自查后继续条目，不把结构展示变成人工审批。只要求结构时完成该范围；仅明确要求结构确认时等待这版确认。

普通编号正文应有独立可定位的来源节点；一份编号BOM或一次完整试验可以保持整体并保留内部组成。先判断原文实际组织，再用下述工具绑定，不按解析器容器或页边界决定业务结构。

This is the entry for a new Map or a bounded structural revision. Reuse the supplied role, version and scope. With task tools use the returned task state and targeted reads; in a script-only plugin use the source/input manifest and CLI `catalog`; in a native host, `reqpilot_context` identifies source/reading paths, tools and the evidence directory. Do not expect native-host tools in a standalone CLI session. Existing capture is evidence, not final ownership; do not recreate it when it already matches the original.

After compiling a meaningful scope, use the returned `source_audit` and [source-first coverage/order check](../reqpilot/references/tools-map-audit.md). Inspect exact unassigned ranges on the authorized pages and the expanded tree, not just an aggregate count or a correctly sorted flat node array. Parallel parser representations are not extra business items. Preserve source order through actual locators; original labels are not sort keys.

For a Map-only task, original numbered leaves still belong in the structure now. Postponing SRC/REQ and engineering Snn does not postpone original boundaries. A `numbered_body_groups` lead means multiple original numbers remain inside one owner's body: split into independently addressable source nodes unless the source establishes a complete-unit exception such as one BOM/test, whose internal structure remains intact.

Across a page break, check that continuing original numbers retain their common parent and governing prefix until a source-supported boundary. `numbered_parent_change_leads` identifies a candidate break for inspection; it cannot choose the correct parent. Do not silently promote a continued numbered item because it appears at the top of the next page. Keep materially uncertain applicability explicit.

Keep pure table captions/continuation labels with the logical table title and exact original evidence; they do not require separate chapters or SRCs. If a prior Map made them body content, use the [existing caption repair](../reqpilot/references/tools-map-edit.md#repair-a-misplaced-pure-caption) before items. Operative conditions in captions/headers must still remain with their governed business content.

**Read and save:** task tools offer source_read with source/page/part views and version-bound continuation requests; use those directly. In a script-only host, when offered, call `inspect-source` with `view:"authoring"`, the actual `source_ir`, and a page/query/index selection. It returns complete selected text, ready-to-use Map refs, table fields and continuation arguments. Check original pixels and governing context as needed. Save a coherent, source-supported scope promptly through the selected task entry; task tools can use outline and the existing [incremental Map authoring](../reqpilot/references/tools-map-edit.md) remains available. Expand source investigation when needed to establish a boundary or parent before committing that scope. Do not first load the item, classification, analysis or export guides for a Map-only task. Native shell inspection stays available; use the absolute `native_execution.evidence_directory` as workdir rather than assuming the skill runtime is the source directory.

**Map contract:** preserve source wording, numbering, direct/trailing body text, actual parents and source order. Numbered body defaults to meaningful numbered leaves; BOM parts or steps jointly forming one complete test may remain a group with internal structure intact. Use the editor's `numbered_body` for a numbered obligation without a separate heading; it binds the number and keeps the obligation as body. COVER/TABLE_OF_CONTENTS/DOCUMENT_CONTROL are whole navigation/control blocks without per-entry SRC; independent front-page obligations retain their actual body scope. Tables stay content under their owner and keep embedded images. Containment is not engineering derivation. Preserve ambiguity and uncovered ranges; a local selection does not authorize discarding other content in the same page frame. Preserve evidenced governing parents even when they start on an earlier page.

**Express the intended effect:** every `logical_tables` entry creates a table extraction scope; a `layout_table` or similar role label does not make it reference-only. For a carrier kept just for original inspection, use node `evidence_refs` as described in the editor guide. Keep real business tables and their actual child relationships. If normal capture drops original glyphs, `capture-pdf-text` can append verified PDF drawing-text observations while preserving old refs. Compare the original pixels, then use the returned capture and a local edit; clipping/visibility uncertainty remains explicit. Neither feature changes boundaries automatically.

For scanned/outlined text or missing table cells, use the available [OCR preparation and transcription tools](../reqpilot/references/source-reading.md#use-the-available-reading-tools-to-save-usable-source). They return normal Map refs while retaining visual provenance. Check numeric alternatives and source pixels before adopting corrected text; a table OCR region does not decide whether its numbered rows are separate clauses or one complete BOM/test.

**Revise and check:** use the compact `review`/`review_read`, but answer two questions from the original: what governs this scope, and where does it end? Its displayed ancestor chain is your authored chain, not an independently recovered source outline. A governing heading may start earlier than the adjacent page; inspect enough original context to establish it or report the unresolved relationship. Then compare body/heading roles, tables/images and continuation with the saved view. Empty `review_leads` is not semantic approval. Apply supported corrections against `map_dir` and recheck the affected context; a failed edit preserves the previous version. Do not wait for user feedback to repair an observed error. After reasonable source investigation, retain unresolved relationships with their locations and continue the rest of the requested scope. Honor an explicitly requested confirmation before items.

Consult [source-reading cases](../reqpilot/references/source-reading.md) when a specific role/heading/visual/attachment question remains, or [table cases](../reqpilot/references/tables-and-relations.md) for business extent, sharing and nesting. `agent_display_label` may explain a table while keeping its original title/cells. The [explicit Map syntax](../reqpilot/references/tools-map.md) is the fallback for hosts without incremental editing or for a required low-level field. Native Office locations remain native; do not fabricate PDF pages or duplicate cell paragraphs already represented by a table. The [shared contract](../reqpilot/references/business-contract.md) applies when moving to item/judgment/delivery stages.
